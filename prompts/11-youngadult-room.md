# 11. 청년기 방 — 자기 방

## 목표

스펙 5.5를 구현한다. 이 방은 `고위험계약`, `연락차단`, `퇴사`, `도박파산` 네 가지 플래그를 처음으로 모두 다루고, 이 플래그들은 12번(엔딩 판정)에서 그대로 소비되므로 플래그 이름과 해제 조건을 정확히 맞추는 것이 중요하다.

## 선행 조건

10-adolescence-room.md 완료.

## 참고 스펙 섹션

`docs/spec.md` 5.5(청년기 — 자기 방) 전체.

## 구현 지시사항

1. **방 테마:** 자취방/사무실/체육관/거리 조명이 섬처럼 연결된 구성(단일 NavMesh, 2.4 규칙 유지). 가구 배치가 "아이가 바꿔 둔" 느낌을 주도록 09/10번과 다른 배치 톤(예: 비대칭적 배치)으로 꾸민다.
2. **도구 사용 제약:** `RelationshipState.Trust < 30`이면 아이가 도구 접촉을 회피하고, 도구 사용 후 15초 동안 자신의 기존 활동(현재 목적지)을 그대로 이어간다(07번 `ComplianceStateMachine`에 새로운 조건부 저항 규칙 추가 — `Trust < 30`일 때는 순응 임계점 점수 누적 자체를 15초간 일시 정지시키는 방식으로 구현). `Trust >= 70`이면 조언(도구 접촉)을 받아도 최종 경로(= 다음 자율 선택)는 08번 `ItemChoiceModel`의 선호 기반 결과를 그대로 따르게 한다(= 순응이 일시적으로 발생해도 효과 적용 후 복귀하는 다음 선택에는 영향을 주지 않음 — 이미 07번 설계가 "영구 고정 아님"이므로 추가 구현 없이 동작해야 함, 여기서는 Trust>=70일 때 순응 임계점 자체를 약간 높이는 보정을 추가할지 설계 판단 후 근거를 남긴다).
3. **일반 물품 8개** (대기업 면접실, 연구·창작 스튜디오, 프로 경기장, 동네 작은 일터, 친구·연인의 저녁 식탁, 투자·과소비 계약서, 쉬어 가는 공원, 부모에게 쓰는 편지) 배치.
   - `투자·과소비 계약서`: `고위험계약` 플래그를 세운다(스펙 5.5 본문에서 "★ 물품과 별개로 일반 물품도 같은 플래그를 세운다"고 명시).
   - `부모에게 쓰는 편지`: Trust 값에 따라 편지 내용 텍스트가 달라지는 분기(최소 2~3단계 — 높음/중간/낮음)를 만든다.
4. **★ 극단 물품 5개** (모든 것을 건 창업 계약, 세계 선수 선발전, 부모 연락 차단과 독립 선언, 충동적인 여행과 퇴사, 반짝이는 도박장) 배치, 각각 플래그 세팅:
   - 창업 계약 → `고위험계약` 플래그(이미 세워져 있으면 중복 없이 유지).
   - 독립 선언 → `연락차단` 플래그.
   - 여행/퇴사 → `퇴사` 플래그.
   - 도박장 → `도박파산` 플래그.
5. **도박 파산 처리 (스펙 "도박 파산 처리 [통합]" 문단, 9.5 검증 대상):**
   - 첫 방문: 짧은 당첨 연출 → 반복 방문의 시간 경과를 압축한 연출(예: 달력이 빠르게 넘어가는 몽타주) → 표의 손실 수치(+25/-12/-18/-22/-20)와 `도박파산` 플래그를 **한 번만** 적용.
   - 같은 회차에서 도박장을 재방문해도(= `ItemSlot`이 이미 첫 방문 처리했으므로 자동으로 재방문은 수치 재적용 없음) 대사만 달라진다.
   - 공원/편지를 도박 파산 이후에 방문해도 파산 플래그는 유지되고 엔딩 대사만 달라진다(= 플래그는 해제되지 않음 — `연락차단`/`퇴사`와 달리 `도박파산`에는 해제 조건이 스펙에 없음을 명확히 구분).
6. **플래그 해제 로직:**
   - `연락차단` 플래그가 세워진 뒤 `부모에게 쓰는 편지`를 자율 방문하면 → `연락차단` 해제 + `Trust += 10`.
   - `퇴사` 플래그가 세워진 뒤 `동네 작은 일터`를 방문하면 → "새 일의 시작" 서사로 연결(플래그 자체를 해제하는지, 해제 없이 서사만 바뀌는지는 스펙에 명시되지 않았으므로 합리적으로 정하고 근거를 남긴다 — 권장: 12번 엔딩 판정에서 `퇴사` 플래그는 "한 번이라도 세워졌는지"가 아니라 "방 종료 시점에 활성 상태인지"로 평가하도록 설계하면 두 플래그 모두 일관된 규칙이 된다).
   - `고위험계약` 플래그는 해제 조건이 스펙에 없으므로 방 종료까지 유지.
7. **복도 4:** 06번 재사용. "부모가 가구를 만지는 손보다 아이가 직접 여는 문"을 보여주는 비주얼, 방문했던 물품 3개 + 마지막으로 받은 편지 한 줄 플래시백.
8. **엔딩 판정용 최종 상태 기록:** 방 종료 시점의 S/I/H/P/L/R, Trust, 그리고 모든 플래그(`도박파산`, `고위험계약`, `연락차단`, `퇴사`, `비행기록`)의 최종 상태를 `GameState.FinalYoungAdultSnapshot`으로 한 번에 스냅샷 저장한다 — 12번(엔딩 판정)이 이 스냅샷 하나만 보고 판정하도록 인터페이스를 깔끔하게 만든다.

## 완료 조건 (Acceptance Criteria)

- [ ] 13개 물품(일반 8 + ★ 5) 모두 배치되고 최초 방문 시 정확한 효과/플래그가 적용된다.
- [ ] 도박장 재방문 시 수치가 중복 적용되지 않는다(9.5 검증).
- [ ] `연락차단` → 편지 방문 → 플래그 해제 + Trust+10이 정확히 1회 발생.
- [ ] `투자·과소비 계약서`와 `창업 계약` 둘 다 방문해도 `고위험계약` 플래그가 중복 처리 없이 하나만 유지된다.
- [ ] `Trust < 30`일 때 도구 사용 후 15초간 기존 활동이 유지되는지 수동/자동 테스트로 확인.
- [ ] `FinalYoungAdultSnapshot`이 실제 플레이 결과와 정확히 일치한다(로그 대조).

## 보고

13개 물품 배치, 플래그 세팅/해제 테스트 결과, 스펙에 명시되지 않아 직접 정한 규칙(퇴사 플래그 해제 여부, Trust 임계값 등)과 근거를 보고한다.
