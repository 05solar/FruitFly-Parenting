# 10. 청소년기 방 — 갈림길

## 목표

스펙 5.4를 구현한다. 히든 의상 조건, 반항 관련 ★ 물품(`비행기록` 플래그 포함), R≥60 청소년기 종료 특별 이벤트(비행·흡연 연출)까지 완성한다.

## 선행 조건

09-childhood-room.md 완료.

## 참고 스펙 섹션

`docs/spec.md` 5.4(청소년기 — 갈림길) 전체, 4.5(R≥35/R≥60 플래그 — 07번에서 이미 노출됨).

## 구현 지시사항

1. **방 테마:** 학교 복도·운동장·밤하늘 창문이 한 방에 겹치는 비주얼(2.4/2.5 규칙 — 바닥 재질/벽 그림/조명으로만 구분, 단일 NavMesh).
2. **기본 의상 vs 히든 의상 판정:** 방 진입 시점에 09번에서 기록해 둔 "영유아기 종료 S", "아동기 종료 S"를 읽어 다음을 판정한다.
   ```
   hiddenCostume = (infantEndS >= 70 AND childhoodEndS >= 70) OR (average(infantEndS, childhoodEndS) >= 75)
   ```
   - 이 판정은 순수 함수(`CostumeEvaluator.ShouldWearHiddenCostume(infantEndS, childhoodEndS)`)로 작성해 EditMode 테스트가 쉽도록 한다.
   - 히든 의상(검은 반팔티 + 녹색 바지)을 입어도 모든 선택/엔딩이 동일하게 열려 있어야 한다 — 의상 분기가 수치나 확률에 영향을 주지 않는다는 것을 코드 주석과 테스트로 명시한다(= 순수 비주얼 플래그).
3. **일반 물품 8개** (입시 책상, 동아리 작업대, 경기장, 상담실, 친구와 옥상 별보기, 무단 밤샘 놀이, 아르바이트 계산대, 부모와 대화 의자)를 배치. `부모와 대화 의자`는 `RelationshipState.Trust`가 낮으면(기준값은 스펙에 명시 없음 — 합리적 임계값을 정하고 근거를 남김) 처음엔 앉지 않는 거부 애니메이션을 재생하고, 이후 접근 시도는 허용한다(완전 차단 아님).
4. **★ 극단 물품 5개** (전교 1등 합숙반, 전국 선발 훈련소, 교칙에 맞서는 공개 공연, 학교를 빠지고 떠난 하루, 친구 무리의 절도 제안) 배치. `친구 무리의 절도 제안` 방문 시 `비행기록` 플래그를 `GameState`에 세운다(불/true 플래그 저장, 11/12번 프롬프트에서 읽음).
5. **"저쪽에 가 보고 싶어" 대사 이벤트:** 아이가 처음으로 선호를 말로 표현하는 대사 트리거(어떤 조건에서 발생시킬지 스펙에 상세 조건이 없으므로, "자율 선택으로 특정 물품에 3번째 접근할 때" 등으로 합리적으로 설계하고 근거를 보고서에 남긴다). 이후 좋아하는 물품으로 가는 길을 보호자가 거듭 막으면(= 07번 `ComplianceStateMachine`의 특정 태그에 대한 반복 저지 횟수를 카운트) 대사가 "그냥 시키는 대로 할게" 또는 "이번엔 내가 골라 볼게"로 갈린다(R 수치 또는 저지 횟수 임계값으로 분기 — 설계 근거를 남긴다).
6. **30초 기다림 이벤트:** 방 종료 직전(마지막 90초 구간, 05번의 "마지막 90초 휴식 선택 가중치 증가"와 겹치는 시간대) 플레이어가 도구를 내려놓고(= 일정 시간 `ToolUsed` 이벤트 없음) 30초를 채우면 아이가 자기 선택을 말하는 대사가 재생된다.
7. **청소년기 종료 특별 이벤트 (비행·흡연 연출):** 07번에서 노출한 `IsFlightSmokeEventTriggered`(R≥60) 플래그를 출구가 열리는 시점에 확인한다.
   - R≥60: 복도 전환 전에 초파리가 날개를 펴고 방 안을 날아다니는 연출(플레이어 카메라 고정, 초파리만 공중 이동) → 창가에 내려앉아 담배 연출(짧은 파티클/애니메이션 placeholder) → 10~15초 후 스스로 담배를 끄고 문으로 이동. 방당 1회만 재생(이미 재생했으면 다시 트리거되지 않도록 방 단위 플래그로 가드).
   - R≤59: 이 연출 없이 기존 복도 3 연출로 즉시 진행.
   - 이벤트 발생 여부와 당시 R 값을 `GameState`에 "청소년기 종료 기록"으로 저장(12번 엔딩 판정/회고 갤러리에서 사용).
8. **복도 3:** 06번 `CorridorRecapController` 재사용. "벽 장식이 부모의 사진에서 아이의 낙서와 친구 사진으로 바뀐다" — 이 비주얼 전환을 Trust 값에 따라 그라데이션으로 구현(낮은 Trust = 낙서/친구 사진 비중이 큼, 높은 Trust = 여전히 부모 사진 일부 유지 등, 세부 비율은 합리적으로 설계).

## 완료 조건 (Acceptance Criteria)

- [x] 히든 의상 조건이 `CostumeEvaluator`의 EditMode 테스트로 정확히 검증된다(경계값: S=69/70, 평균 74/75 각각 확인).
- [x] 히든 의상 착용 여부가 수치/확률/엔딩 가능성에 영향을 주지 않는다(동일 시드, 의상만 다른 두 케이스를 비교해 다른 결과가 나오지 않는지 확인).
- [x] `친구 무리의 절도 제안` 방문 시에만 `비행기록` 플래그가 세워지고, 다른 ★ 물품 방문으로는 세워지지 않는다.
- [x] R=59와 R=60 경계에서 비행·흡연 이벤트 발생 여부가 정확히 갈린다(9.7 검증 항목).
- [x] 비행·흡연 이벤트 중 플레이어 카메라가 고정되어 멀미 유발 요소(강제 이동/회전)가 없다.
- [x] 이벤트는 방당 정확히 1회만 재생된다(같은 방에서 조건을 다시 만족시켜도 재생되지 않음).

체크는 모델·저장된 씬의 자동 검증 기준이다. 의상만 다른 회차의 1,000회 선택열과 엔딩용 수치·사건 플래그가 동일하며, 실제 14개 엔딩 계산은 12번 범위다. 카메라 강제 이동·회전이 없다는 것은 입력을 주는 PlayMode 검사로 확인했으며 HMD에서의 멀미 체감·양안 검사는 아직 수행하지 않았다. 구현과 임계값의 근거는 [`docs/tech-stack.md` 13절](../docs/tech-stack.md#13-10-청소년기-방--갈림길)에 기록했다.
