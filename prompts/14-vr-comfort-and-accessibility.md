# 14. VR 편안함·접근성 패스

## 목표

스펙 8장의 기준을 전체 게임(01~12번 결과물)에 걸쳐 일괄 점검하고 보강한다. 이 단계는 새 기능을 추가하는 것이 아니라 **이미 만든 모든 방/복도/UI가 8장 기준을 지키는지 감사(audit)하고 빠진 부분을 고치는** 단계다.

## 선행 조건

12-middleage-and-endings.md 완료 (전체 루프 완결).

## 참고 스펙 섹션

`docs/spec.md` 8장(VR 상호작용·연출 기준) 전체.

## 구현 지시사항

1. **이동 감사:** 모든 씬(방·복도)에서 플레이어 이동이 04번의 휠체어 연속 로코모션(왼손 스틱) 하나로만 이루어지는지 확인한다 — 순간이동, 시선 기반 이동, UI 버튼 이동 등 다른 이동 경로가 코드베이스에 남아 있지 않은지 전체 검색으로 확인하고 있으면 제거한다(스펙 8장 "이전의 제자리 관찰점 전환과 기본 순간이동은 사용하지 않는다"). 휠체어가 정지 상태일 때 입력이 없으면 절대 움직이지 않는지(관성으로 미끄러지지 않는지) 재확인한다.
2. **편안함 감사:** 01~12번에서 만든 모든 카메라/연출 코드를 검색해 자동 카메라 이동, 급회전, 강제 흔들림이 있는지 점검한다. 발견되면 해당 프롬프트의 산출물을 수정한다(예: 10번의 비행·흡연 이벤트가 카메라를 고정한다고 명시했는지 재확인). 모든 방-복도 전환 페이드가 0.5초 이상인지 수치로 확인한다.
3. **입력 접근성:** 왼손 이동/오른손 전기 봉이라는 고정 역할 배치는 스펙 8장에서 기본 규칙으로 명시되어 있으므로 좌우손 바꾸기는 제공하지 않는다. 대신 (a) 휠체어 회전 속도 조절, (b) 이동 중 시야 축소(비네팅) on/off, (c) 사용자 신장에 따른 높이 보정(XR Origin의 카메라 높이 자동/수동 조정)을 설정 메뉴에 추가한다. 아직 설정 메뉴가 없다면 최소한의 UI(씬 시작 전 또는 일시정지 메뉴)로 만든다.
4. **자막:** 모든 대사/내레이션(05~12번에서 만든 서사 텍스트들)이 예외 없이 자막으로도 표시되는지 코드 검색으로 확인한다(음성이 아직 없다면 텍스트 UI 자체가 자막 역할을 하므로, 텍스트 없이 소리/애니메이션만으로 전달되는 정보가 있는지가 핵심 점검 대상 — 예: 비행·흡연 이벤트, 감전 연출).
5. **색 외에 모양으로 수치 표현:** 수치 변화 UI(04번에서 만든 스탯 변화 팝업 등)가 색만으로 증감을 구분하는지 점검하고, 색맹 사용자를 위해 ▲/▼ 같은 모양 아이콘을 추가한다. 06번 복도의 "개입 흔적" 비주얼(흔들린 사진 등)도 색에만 의존하지 않는지 확인한다.
6. **피드백:** 모든 `ItemSlot`(03번) 진입 전 바닥 그림자/은은한 소리가 재생되는지, 1회 적용 물품의 조명이 옅어지는 처리가 실제로 들어가 있는지 전수 점검한다. 수치 변화 팝업이 시야 중앙(플레이어가 보고 있는 정면 가운데)을 가리지 않는 위치에 뜨는지 확인한다.
7. **소리:** 06번에서 구현한 방별 배경음(자장가/장난감과 운동장/교실과 저녁 바람/생활 소음)과 복도 메아리 크로스페이드가 실제로 시기별로 다르게 들리는지 점검한다.
8. **설정 저장:** 이번 단계에서 추가한 접근성 설정(손 바꾸기, 높이 보정, 자막 on/off는 기본 항상 on이므로 토글 불필요할 수 있음 — 다만 폰트 크기 등은 토글 고려)이 02번 `SaveSystem`과 별도로 플레이어별 로컬 설정(PlayerPrefs 등)에 저장되어 회차 리셋과 무관하게 유지되는지 확인한다.

## 완료 조건 (Acceptance Criteria)

- [ ] 8장의 각 항목(이동/편안함/피드백/소리/저장)에 대해 "어느 코드/씬에서 지키고 있는지"를 체크리스트로 작성하고 모든 항목이 체크된다.
- [ ] 자동 카메라 이동/급회전/강제 흔들림이 전체 코드베이스에 하나도 없다(검색으로 확인, 예외가 있다면 명시적으로 사유를 남기고 사용자에게 보고).
- [ ] 모든 페이드 전환이 0.5초 이상이다.
- [ ] 회전 속도 조절/시야 축소(비네팅)/높이 보정 설정이 실제로 동작한다.
- [ ] 순간이동·시선 이동·UI 버튼 이동 등 휠체어 연속 로코모션 이외의 플레이어 이동 경로가 코드베이스에 남아 있지 않다.
- [ ] 수치 변화 표시가 색+모양 이중 인코딩을 쓴다.
- [ ] 접근성 설정이 다시 시작/재실행 후에도 유지된다.

## 보고

8장 체크리스트 전체 결과, 발견해서 수정한 위반 사례 목록(특히 제거한 잔존 순간이동/시선 이동 경로가 있다면), 휠체어 편안함 설정(회전 속도, 비네팅, 높이 보정)의 기본값과 근거를 보고한다.
