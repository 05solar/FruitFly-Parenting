# 초파리 육아 VR 게임 — 행복한 초파리 만들기

VR 육아·관찰 시뮬레이션 게임. 플레이어는 초파리 아이의 보호자가 되어 시대별 방을 거치며 자유롭게 행동하는 아이를 지켜보거나 '사랑의 매'로 방향을 유도한다. 개입의 빈도와 강도가 아이의 성향과 부모-자녀 관계, 그리고 14가지 엔딩으로 돌아온다.

Unity 프로젝트 본체는 이 루트의 `Assets/`, `Packages/`, `ProjectSettings/`에 있다.

2026-11-25 방 아트 업데이트: Kenney Furniture Kit의 가구 모델과 Poly Haven 원목 바닥을 영유아·아동·청소년·청년 방에 적용했다. 창문, 커튼, 벽 패널, 액자, 러그와 천장 조명을 추가했으며, 47개 상호작용 지점의 기존 충돌·NavMesh는 유지한다. 두 에셋은 CC0이며 [원본 출처와 라이선스](Assets/_Project/Art/ThirdParty/README.md)를 포함했다. `RoomArt`가 플레이 시작과 씬 로드 시 적용하고, 에셋을 다시 생성하려면 Unity 메뉴 `Fruit Fly Parenting/Art/Prepare Room Assets`를 사용한다.

전동 휠체어·전기봉도 CC0 모델로 교체했다. 휠체어 왼쪽 앞에 조이스틱과 상태 표시 패널을 배치하여 기본 착석 시점에서 볼 수 있고, 방향키 또는 VR 왼손 스틱 입력에 따라 조이스틱이 기울어진다. PC의 전기봉은 오른쪽 시야에 보관되며 클릭하면 기존 접촉 방식으로 뻗는다. VR에서는 오른손 추적을 따른다. [에셋 출처](Assets/_Project/Art/ThirdParty/PlayerEquipment/License.txt), [착석 화면](docs/images/player-equipment-seated.png), [휠체어 외형](docs/images/player-equipment-exterior.png), [검증 기록](docs/reports/player-equipment-validation.json)을 참고한다. 에셋 재생성 메뉴는 `Fruit Fly Parenting/Art/Prepare Player Equipment`이다.

## 기술 스택 요약

- **엔진:** Unity (URP), XR Interaction Toolkit + OpenXR
- **1단계 타깃:** PCVR (개발/반복 속도 우선)
- **2단계 타깃:** Meta Quest 스탠드얼론 (15번 프롬프트에서 최적화)

자세한 내용은 [`docs/tech-stack.md`](docs/tech-stack.md) 참고.

## 시작하는 법

1. [`docs/spec.md`](docs/spec.md)를 읽고 게임 전체 설계를 이해한다.
2. [`prompts/README.md`](prompts/README.md)의 사용법을 따라 `prompts/01-project-setup.md`부터 순서대로 Claude Code에 지시한다.
3. 각 프롬프트의 "완료 조건"을 전부 통과해야 다음 번호로 넘어간다. 자동 테스트(EditMode/PlayMode)와 16번의 헤드리스 시뮬레이션으로 수치·엔딩·경계 조건을 검증하고, 17번에서 사람이 직접 플레이하며 느낌을 다듬는다.

## 현재 진행 상태 (2026-11-25)

- **HUD·대사 수정:** 왼쪽 한 열의 작은 상태 막대에 현재값만 표시한다. 성장일지 상자·카드 배경·우측 상단 위치 표시는 제거했다. 상호작용 대사는 연령별 말투로 바꾸고 초파리 머리 위 작은 반투명 말풍선에 표시한다. 메뉴 명칭은 ‘설정’이다. [구현·검증](docs/ui-journal-design.md). 최신 실행 파일은 `Builds/FlatHUD/FruitFlyParenting.exe`다.
- **17단계 진행 중:** 아이 이름표·위치 안내, PC/XR별 조작 안내, 회복 물품 표시와 세이브가 분리된 플레이테스트 기록 도구를 추가했다. [실행 안내](docs/playtest-guide.md), [세션 양식](docs/playtest-log-template.md), [검증 보고](docs/playtest-validation.md). 실제 사람의 세 스타일 전체 완주·체감 평가·관계 중심 L=100 확인은 남아 있다.
- **16단계 완료:** 씬 로드 없이 3,494회와 동일 조건 재실행을 약 130초에 검증했다. 14개 엔딩 모두 도달, 수치·중복 효과 위반 0건, 전체 로그 재현율 100%다. 도달 불가능했던 히든 엔딩의 신뢰 경로를 첫 자율 관계 방문 보상으로 보완했다. EditMode 259개와 PlayMode 76개를 검증했고, 성장 네 방의 FlyAgent 및 중년기 휠체어를 각각 5분 검사했다. [실행법·빈도표·수정 내용·검증 범위](docs/simulation-validation.md).
- **PC 조작 추가(2026-11-25):** VR 기기가 없으면 방향키/WASD로 휠체어를 전후 이동·좌우 회전하고, 마우스 오른쪽 드래그로 시점을 조절한다. 가까운 아이에게는 왼쪽 버튼을 눌러 봉을 내밀 수 있다. 설정·엔딩 버튼은 마우스로 클릭하며 Esc는 마우스 잠금 해제다. VR 기기가 활성화되면 기존 왼손 스틱/오른손 봉으로 전환한다. 새 Windows 실행 파일은 `Builds/PC/FruitFlyParenting.exe`다. 프롤로그 60초 동안은 기존 연출대로 이동을 잠근다. 전체 PlayMode 74개 통과 후, 씬의 끊어진 참조를 정리하고 PC·편안함 통합 11개와 씬 감사 5개를 재검증했다. Windows 실행본은 기존 OpenXR/XRI 격리 프로젝트로 빌드했으며 루트 Meta XR 설정은 유지했다. [검증 범위](docs/reports/desktop-controls.json).

- 이 PC에는 OpenXR 런타임과 연결된 HMD가 없어 양안 출력·실제 컨트롤러 추적을 검증하지 못했다. 15단계에서는 설치된 Android Build Support로 APK 생성 및 구조 검증을 수행한다. 사용자 Standalone Meta XR 설정의 MRUK 실행 문제와 실기기 검증은 남아 있다.
