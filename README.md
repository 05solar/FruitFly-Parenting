# 초파리 육아 VR 게임 — 행복한 초파리 만들기

VR 육아·관찰 시뮬레이션 게임. 플레이어는 초파리 아이의 보호자가 되어 시대별 방을 거치며 자유롭게 행동하는 아이를 지켜보거나 '사랑의 매'로 방향을 유도한다. 개입의 빈도와 강도가 아이의 성향과 부모-자녀 관계, 그리고 14가지 엔딩으로 돌아온다.

## 이 저장소의 구조

```
docs/
  spec.md             # 기획 명세서 (단일 진실 소스 — 모든 구현 판단의 기준)
  tech-stack.md       # Unity + XR Interaction Toolkit 기술 스택과 프로젝트 규칙
prompts/
  README.md           # 단계별 구현 프롬프트 사용 가이드
  01-17...            # 번호 순서대로 실행할 구현 프롬프트 17개
```

(Unity 프로젝트 본체는 `01-project-setup.md` 실행 후 이 루트 아래 `Assets/`, `Packages/`, `ProjectSettings/` 등으로 생성된다.)

## 기술 스택 요약

- **엔진:** Unity (URP), XR Interaction Toolkit + OpenXR
- **1단계 타깃:** PCVR (개발/반복 속도 우선)
- **2단계 타깃:** Meta Quest 스탠드얼론 (15번 프롬프트에서 최적화)

자세한 내용은 [`docs/tech-stack.md`](docs/tech-stack.md) 참고.

## 시작하는 법

1. [`docs/spec.md`](docs/spec.md)를 읽고 게임 전체 설계를 이해한다.
2. [`prompts/README.md`](prompts/README.md)의 사용법을 따라 `prompts/01-project-setup.md`부터 순서대로 Claude Code에 지시한다.
3. 각 프롬프트의 "완료 조건"을 전부 통과해야 다음 번호로 넘어간다. 자동 테스트(EditMode/PlayMode)와 16번의 헤드리스 시뮬레이션으로 수치·엔딩·경계 조건을 검증하고, 17번에서 사람이 직접 플레이하며 느낌을 다듬는다.

## 진행 단계 한눈에 보기

| 단계 | 내용 |
|---|---|
| 01~03 | 프로젝트 셋업, 핵심 데이터 아키텍처, 방 쉘/NavMesh |
| 04 | 도구(사랑의 매)와 기본 스트레스 공식 |
| 05~06 | 영유아 방 수직 시연, 복도/전환 시스템 |
| 07~08 | 반항·강제훈련·순응 상태머신, 선호/회피 학습 |
| 09~12 | 아동·청소년·청년·중년 방, 14개 엔딩 분기 |
| 13 | 초파리 뇌지도(FlyWire 커넥톰) 시각화 — 별도 실험 빌드 |
| 14~15 | VR 편안함/접근성 감사, Quest 최적화 |
| 16~17 | 자동 시뮬레이션 전수 검증, 수동 플레이테스트·밸런스 |

게임 수치·태그·서사·엔딩 규칙은 이 기획을 위해 창작된 것이며, FlyWire 커넥톰 데이터(7장)는 연출·시각화 참고 자료로만 쓰이고 실제 초파리 행동이나 인간 발달을 재현한다고 주장하지 않는다.
