PlayMode 전체 실행 `Logs/Step14Project/Logs/step17-PlayMode.xml`은 75개 통과/10개 실패였다. 새 테스트가 UI 제거 후 방 갱신을 계속하고 씬을 남겨 다음 테스트까지 오염시킨 테스트 정리 문제였다. 방 갱신을 멈추고 테스트 사이 게임 씬을 정리하도록 수정했다. Unity 자체 테스트 러너 씬은 유지한다. 수정 후 `Logs/Step14Project/Logs/step17-support-final.xml`의 새 지원 테스트 9개와 다음 학습 테스트 4개, 총 13개가 모두 통과했다. 고유 테스트 이름별 최종 결과 85개를 확인했으며 단일 XML 85개 통과라고 주장하지 않는다.

새 검사는 실제 영유아기 아이 이름표의 생성·복도 진입 시 숨김·제거, 앞/뒤/좌/우 안내, 기본 세이브 보존 및 기록 세이브 분리, 이벤트 중복 기록 방지, 엔딩 선택과 카드 표시 구분, 재시작 기록 분리, 일시정지 시간, 자동 증거의 수동 검토 대기 상태를 검사한다.

16단계 시뮬레이션 재실행은 3,015개 회차와 같은 조건 재실행 3,015개를 약 143초에 완료했다. 14개 목표 엔딩 모두 도달, 재현 일치 100%, 위반 0건이다. 기본 정책 각 1,000개와 기존 시드를 힌트로 재실행한 목표 엔딩 및 관계 사례를 포함한다. 이 빈도는 실제 플레이어의 엔딩 확률이 아니다.

처음 PlayMode 검사에서 `-nographics` 모드의 URP 렌더러가 종료됐다. 이 실행은 통과로 세지 않으며, DX11을 사용하는 검사로 재실행했다. 사용자 Meta XR 209 설정을 덮어쓰지 않고 기존 OpenXR/XRI 검증 프로젝트를 사용한다.
