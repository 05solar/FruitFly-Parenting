# HUD와 캐릭터 대사

2026-11-25 사용자 피드백을 반영한 현재 표시 규칙이다.

- 수치는 왼쪽 한 열의 개별 막대다. 글씨·막대·간격을 기존의 65% 크기로 줄였으며 `58`처럼 현재값만 표시한다. `/100`, 카드 배경, 성장일지 제목 상자는 없다.
- 우측 상단의 초파리 방향·거리 표시는 제거했다.
- 가구 상호작용은 화면 하단 나레이션 대신 초파리 머리 위 작은 말풍선으로 표시한다. PC와 VR 모두 캐릭터를 따라가는 World Space 캔버스이며 카메라를 향한다.
- 말풍선은 흰 글씨와 검정 외곽선, 불투명도 28%의 검정 배경을 쓴다. 대사 길이에 맞게 상자 크기를 조정하고 3.5~6초 뒤 숨긴다. 설정 메뉴·방 퇴장 때도 숨기며, 길 찾기를 끈 특수 연출 중에는 계속 캐릭터를 따라간다.
- 영유아 9종, 아동 12종, 청소년 13종, 청년 13종의 가구를 포함해 총 47종의 첫 방문·재방문 94개 문구와 회상 대사를 직접 말하는 투로 수정했다. 실제 ItemDefinition 에셋과 씬 생성용 카탈로그를 함께 수정했다.
- 영유아는 `안아 줘…`, `또 볼래!` 같은 짧은 말, 아동은 놀이·친구 중심의 말, 청소년은 또래·부모·상담 상대에 맞춘 말투, 청년은 일·생활·관계 상황에 맞춘 말투를 사용한다. 행동을 설명하는 문장을 캐릭터에게 붙이지 않는다.
- 종이비행기, 반복 차단·기다림·대화 거절, 청년의 편지·재취업, 도박 장면, 감전·망설임도 직접 대사로 표시한다. 도박 장면의 별도 표지는 `당첨`, `N개월 경과`, `잔액 0` 같은 정보만 남긴다.
- PC 설정 버튼은 우측 최상단에 `설정`으로 표시한다. F9 표시와 단축키를 제거했으며 마우스로 열고 `돌아가기`로 닫는다. VR의 왼손 Y 입력은 유지한다. 도움말은 `조작법`이다. 가구 이름은 별도 텍스트로 표시하며 왼쪽 상태 막대를 가리는 이름표는 PC에서 숨긴다.

기존 Noto Sans CJK KR 글꼴과 OFL 라이선스를 유지한다. 대사 수정은 가구의 효과 수치·태그·관계 조건·엔딩 판정을 바꾸지 않는다.

실행 파일은 `Builds/FlatHUD/FruitFlyParenting.exe`, 실행 스크립트는 `scripts/Start-Playtest.ps1`이다. 기본 창은 1920×1080, PC 전후 이동은 최대 3.2m/s다. 도입부는 남은 시간을 표시하며 Enter 또는 게임 시작 버튼으로 건너뛸 수 있다.

성장 방의 초반 90초 도구 대기는 제거했다. 방 입장 직후부터 휠체어·봉 접촉이 작동하며 `도구 사용까지` 안내도 표시하지 않는다.

도구 대기 제거 후 실행 검사 20개와 모델·시뮬레이션 검사 21개가 통과했다. [검증 기록](reports/unlimited-tools-validation.json).

검증은 대사의 에셋·카탈로그 일치, 전체 가구의 첫 방문·재방문 문구, 말풍선의 캐릭터 추적·일시정지·만료·정리, 화면 나레이션과 위치 표시 제거, 현재값만 표시, PC/VR 전환을 포함한다. 실제 헤드셋 가독성은 별도 확인 대상이다.

가구별 전체 문구는 [대사 목록 CSV](reports/spoken-dialogue-lines.csv)에서 확인할 수 있다. 관련 모델 검사 110개와 PlayMode 검사 19개가 통과했다. 전체 EditMode 실행에서는 260개 중 258개가 통과했으며, PC 검증 프로젝트의 Android 그래픽 API·오디오 가져오기 설정이 Quest 전용 기대값과 다른 2개 검사는 실패했다. 이 작업에서는 사용자 Quest 설정을 바꾸지 않았다. 검증 근거와 실행본 정보는 `reports/spoken-dialogue-validation.json`에 기록한다.
