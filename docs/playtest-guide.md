# 17단계 수동 플레이테스트

현재 상태: **사전 개선 및 테스트 도구 준비, 사람의 전체 회차 검증 대기**. 자동 테스트를 수동 완주로 집계하지 않는다.

## 실행

저장소에서 PowerShell로 실행한다. 스타일은 기록용 이름이며 아이를 자동 조종하거나 수치를 바꾸지 않는다.

```powershell
./scripts/Start-Playtest.ps1 -Style observer
./scripts/Start-Playtest.ps1 -Style overprotective
./scripts/Start-Playtest.ps1 -Style rebellious
# L=100 자연스러운 도달을 별도로 확인할 때
./scripts/Start-Playtest.ps1 -Style relationship
```

한 번에 한 세션씩 플레이한다. 새 실행마다 `PlaytestReports/<실행 ID>/savegame.json`을 사용하므로 기존 일반 게임의 저장 파일을 덮어쓰지 않는다. 다시 시작하면 기록은 별도 `run-*` 폴더로 나뉜다. 이 도구는 중단한 세션의 이어하기 UI를 제공하지 않는다.

최신 HUD 빌드는 `Builds/FlatHUD/FruitFlyParenting.exe`에 있다. 실행 스크립트도 이 경로를 사용한다. Windows 빌드는 OpenXR/XRI 기준의 별도 프로젝트에서 만든다. 루트의 사용자 Meta XR 패키지·설정은 유지하며, Quest 실기기 체감 검증은 따로 필요하다.

- 방향키/WASD: 이동·회전, 마우스 오른쪽 드래그: 시점, Esc: 마우스 해제. PC 전후 이동은 최대 3.2m/s이며, VR 이동과 회전 설정은 유지한다. 실행 스크립트의 기본 창 크기는 1920×1080이다.
- 도입부는 60초 뒤 자동으로 시작하며 남은 시간을 표시한다. `게임 시작` 버튼 또는 PC Enter 키로 바로 영유아 방에 들어갈 수 있다. 설정 메뉴를 열면 도입부와 시작 입력도 일시정지한다. Windows 빌드에는 백그라운드 실행을 켜서 다른 창으로 이동해도 자동 진행이 멈추지 않게 한다.
- 모든 성장 방에서 입장 직후 휠체어·봉을 사용할 수 있다. 초반 90초 대기와 남은 시간 표시는 제거했다.
- 왼쪽 버튼: 가까운 아이에게 봉 내밀기. 우측 최상단 `설정` 버튼으로 설정·일시정지 메뉴를 열고 `돌아가기`로 닫는다.
- F6: 기억에 남는 순간을 시각·방과 함께 기록. F7: 게임 화면 저장.
- 초파리 이름표와 방향·거리 안내로 위치를 찾는다. ‘스트레스 감소’ 표시는 일반 회복 활동을 가리킨다.

PC 기록 단축키는 VR 컨트롤러 동작을 바꾸지 않는다. VR에서는 관찰자가 시각을 메모하거나 세션 후 원본 이벤트를 참고해 실제 기억을 작성한다. PC 화면 검사로 VR 양안 가독성·멀미를 통과 처리하지 않는다.

## 세션 계획

| 스타일 | 직접 할 행동 | 확인할 결과 | 현재 기록 |
| --- | --- | --- | --- |
| 관찰자형 | 도구를 거의 쓰지 않고 관찰, 문이 열리면 다음 방 이동 | 핵심 감정·지루함·자율 행동 | 미실시 |
| 과보호형 | 성과 물품으로 반복·강한 유도 | 강제·반복 훈련·순응의 압박감 | 미실시 |
| 반항 유발형 | 비행 물품 방문과 높은 R 유지 | 비행·흡연 이벤트와 조폭 엔딩의 실제 연출 | 미실시 |
| 관계 중심 | 식탁·대화·편지 등 관계 활동 | L=100의 자연스러운 도달 | 미실시 |

첫 세 스타일은 각각 프롤로그부터 엔딩 카드까지 약 45~60분 전체 회차가 필요하다. 실제 시간이 더 길거나 짧으면 그대로 기록하고 원인을 조사한다. 관계 검증은 실제로 충족한 다른 세션과 겹쳐도 되지만, 16단계의 자동 L=100 사례로 대체하지 않는다. 반항 유발형도 R만 높였다고 조폭 엔딩에 도달했다고 간주하지 않는다.

각 세션에서 [템플릿](playtest-log-template.md)을 복사해 `docs/playtest-logs/YYYY-MM-DD-스타일.md`에 작성한다. 엔딩 카드가 뜨기 전에 기억에 남은 세 순간을 먼저 적고 카드와 비교한다. 시뮬레이션의 정답 경로를 외워 재현하기보다 실제 플레이의 선택과 느낌을 남긴다.

## 원본 기록 해석

- `session.json`: 스타일, 시드, 빌드 GUID, 플랫폼, 경과 시간, 포커스가 있고 일시정지되지 않은 시간, 엔딩 카드 도달 시각. `humanReview=pending`은 사람이 템플릿을 작성·검토하기 전까지 유지한다.
- `events.jsonl`: 실제 GameState 이벤트. 방 진입, 물품 방문, 접촉, 서사, 엔딩을 누적 기록한다.
- `observations.jsonl`: F6 순간 표시, 화면 저장 요청, 포커스 전환, 세션 시작·종료.
- `balance-config.json`: 세션 시작 시 설정 사본. `state.json`: 주기적으로 저장한 상태와 이벤트 전체.
- `screen-*.png`: F7로 저장한 화면. 강제 프로세스 종료 시 마지막 10초의 상태 요약은 없을 수 있다.

포커스 시간은 사람이 실제로 주의를 기울였다는 증거가 아니다. 가속이 관찰되면 `nonRealtimeSpeedObserved`에 남긴다. 자동 실행에는 `-playtest-source automated_smoke`를 붙여 수동 기록과 구분한다. 원본 폴더는 Git 제외이고, 공유할 검토 결과만 문서에 옮긴다.

## 수정 루프

체감 문제를 시각과 근거로 기록 → 먼저 설정값으로 해결할 수 있는지 검토 → 실제 버그·안내 결함은 해당 코드 수정 → 수치/로직 변경 후 16단계 시뮬레이션과 원본 로그 검증 → 같은 조건의 실제 재플레이.

한 번에 여러 수치를 바꾸지 않고 필드별 이전→이후, 이유, 날짜를 기록한다. 아직 수동 평가가 없어 이번 사전 개선에서는 `GameBalanceConfig` 수치를 변경하지 않았다.
